Respostas e objetivos desta atividade:

Quais perguntas de negócio você escolheu, e por quê;
    1. Quais são os meios mais utilizados para pagamento?
  para formar parcerias financeiras como bancos para menores taxa ou facilitar meios de pagamentos em cripto moeda para não pagamento de taxas e impostos
    2. Qual é o status das entregas? Concluídas versus pendentes? 
  organizar o  orçamento de serviços concluido como os que ainda podem sofrer alterações, por exemplo com  à apresentação o dashboard podemos verificar que à maior parte dá receita nem foi entregue,  assim caso ocorra problemas como à entrega esse lucro já não será o mesmo	 
    3. Quantos pedidos foram cancelados? 
  para saber quanto dinheiro foi perdido como cancelamento, porém no banco de dados não explica o motiva delas, assim caso à quantidade de cancelamento seja auto poderia ser interessante levantar os motivos destes cancelamento para saber se é uma questão tangível dá empresa ou nao, como por exemplo 80% dos cancelamentos foi culpa dá demora na entrega e assim ver meios de corrigi los.
    4. Qual região mais compra veículos e quais modelos são os preferidos? 
  seria útil para filtrar à linha de produção e em caso de um local especifico como alta demanda analisar  possíveis aberturas de lojas ou fábricas.
